# Nodal — image manifest

Generate every image with the Codex CLI built-in image tool (never draw with code). Output
file names below are relative to `art/raw/`. Final compressed versions go to `public/`.

## Shared style block (append to EVERY brief)

> Premium product photography render. Soft studio lighting from the top and sides (never a
> flat front light), gentle contact shadow only if the object rests on something, otherwise
> floating. Matte graphite, warm cream and brushed-aluminium materials; tiny accents of
> plasma pink (#ff3d81) and arc blue (#2ea8ff) glow. Original industrial design: NO real
> brand names, NO logos, NO text, NO letters or numbers, NO Apple/Samsung/Sony/Google
> look-alike marks, NO UI screens showing real apps (screens, if any, show abstract soft
> gradients only), NO people, NO hands. One object centred, generous empty margin around it.
> Consistent three-quarter camera angle, slightly from above. Crisp, high detail, true
> proportions.
